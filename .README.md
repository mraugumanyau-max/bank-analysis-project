# Bank Customer Data Analysis

## 1. Project Overview

This project explores a Bank Marketing customer dataset using Python. It uses Pandas to load, inspect, filter, group, and analyse customer information, and Matplotlib and Seaborn to create visualisations.

The analysis focuses on customer demographics, occupations, bank account balances, campaign-related numerical variables, and whether customers subscribed to a term deposit.

## 2. Project Objectives

The objectives of this project are to:

- Load and inspect a customer dataset stored in a CSV file.
- Select relevant columns for analysis.
- Check data types, descriptive statistics, missing values, and duplicate records.
- Explore customer counts by job category and month.
- Examine the distribution of customer bank balances.
- Compare customer age and bank balance.
- Calculate correlations between selected numerical variables.
- Summarise average customer age and bank balance by job category.
- Visualise patterns in the dataset.

## 3. Tools and Libraries

The project uses:

- **Python** – Programming language used for the analysis.
- **Pandas** – Loading, cleaning, filtering, grouping, and analysing tabular data.
- **NumPy** – Imported for numerical computing.
- **Matplotlib** – Creating charts and plots.
- **Seaborn** – Creating statistical visualisations.
- **Jupyter Notebook** – Running the analysis interactively.

## 4. Dataset

The notebook loads a file named `bank_customers.csv` using a semicolon (`;`) as the delimiter:

```python
df = pd.read_csv('bank_customers.csv', sep=';')
```

The analysis uses the following columns:

| Column | Description |
|---|---|
| `age` | Customer age |
| `job` | Customer occupation |
| `marital` | Marital status |
| `education` | Education level |
| `default` | Credit in default status |
| `balance` | Customer account balance |
| `housing` | Housing loan status |
| `loan` | Personal loan status |
| `contact` | Contact communication type |
| `day` | Last contact day of the month |
| `month` | Last contact month |
| `campaign` | Number of contacts during the current campaign |
| `pdays` | Number of days since the customer was last contacted in a previous campaign |
| `previous` | Number of contacts performed before the current campaign |
| `y` | Whether the customer subscribed to a term deposit |

The notebook expects `bank_customers.csv` to be available in the working directory when the notebook is run.

## 5. Data Preparation and Exploration

The notebook performs the following preparation and exploration steps:

1. Loads the CSV dataset into a Pandas DataFrame.
2. Checks the dataset dimensions with `df.shape`.
3. Previews records using `head()`.
4. Inspects column names and data types.
5. Generates descriptive statistics using `describe()`.
6. Removes the `duration` column if it is present.
7. Selects the columns used for the analysis.
8. Converts `month` to a categorical data type.
9. Checks the number of missing values in each column.
10. Examines repeated job values and an example job category.
11. Removes duplicate rows based on the combination of `month`, `job`, and `contact`, then resets the index.

## 6. Analysis and Visualisations

The notebook includes the following analysis:

### Customer job categories

Counts customer records by job category and displays the top 10 job categories in a bar chart.

### Bank balance distribution

Uses a histogram and a kernel density estimate (KDE) plot to explore the distribution of customer account balances.

### Age and bank balance

Creates scatter plots to examine the relationship between customer age and account balance. One Seaborn scatter plot uses the `y` column to distinguish subscription status.

### Numerical variable comparisons

Uses a pair plot to compare `age`, `balance`, `day`, `campaign`, and `previous`, with points grouped by the `y` subscription-status column.

### Correlation analysis

Calculates a correlation matrix for these numerical columns:

- `age`
- `balance`
- `day`
- `campaign`
- `previous`

A Seaborn heatmap displays the correlation coefficients.

### Average bank balance by job

Excludes records where `job` is `unknown`, groups the remaining records by job, calculates the mean and count of `balance`, keeps job categories with at least 10 records, and plots their average balances.

### Average customer age by job

Excludes records where `job` is `unknown`, groups customers by job, calculates the mean age and count for each job category, and sorts the results by average age.
